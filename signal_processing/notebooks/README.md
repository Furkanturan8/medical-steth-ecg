# signal_processing/notebooks/

Analiz notebook'ları.

- `01_ilk_analiz.ipynb` — ana çalışma notebook'u: ham sinyal/FFT, sentetik
  gürültü ekleme, band-pass (20-500 Hz) + notch (50/100 Hz) filtreleme,
  SNR ölçümü, dayanıklılık testi, S1/S2 (kalp sesi) segmentasyonu

Notebook'u çalıştırmak için proje kökündeki `.venv` ortamını Jupyter
kernel olarak seçin ("Python (steth-ecg venv)"). Sonuçların özeti
`results/01_ilk_analiz_rapor.md`'de tutuluyor.
