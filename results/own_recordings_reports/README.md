# own_recordings_reports/

Kendi kayıtlarımızdan (`data/raw/own_recordings/`) üretilen, doktora
gösterilebilecek PCG rapor görüntüleri (zaman domeni + zarf + S1/S2
işaretleme, altında spektrogram). `signal_processing/notebooks/01_ilk_analiz.ipynb`,
Bölüm 14 ile üretiliyor.

Kişisel sağlık verisinden türetildiği için `.gitignore`'daki
`results/own_recordings_reports/*` kuralı gereği bu PNG'ler git'e girmez,
yalnızca local'de tutulur.
