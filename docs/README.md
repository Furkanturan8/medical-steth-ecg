# docs/

Projeye dair yazılı dokümantasyon.

- `sprint_log.md` — yapılan her işin (nerede/ne yapıldı/neden/sonuç) sırayla
  işlendiği günlük; proje geçmişini takip etmek için ana kaynak
- `decisions.md` — alınan önemli mimari/teknik kararlar ve gerekçeleri
  (henüz boş, ilk karar alındığında doldurulacak)
- `notes/` — sık başvurulan teorik kavramların referans notları
- `papers/` — ilgili akademik makale/kaynak PDF'leri
- `diagrams/` — sistem/devre diyagramları
